## B9 有背景圖時開設定卡頓

### 量測方法
自寫 harness(scratchpad,不進 repo):Electron **offscreen 繪製**(不開視窗、不搶焦點、**不送任何 OS 輸入**)載入建置好的 renderer + 假 host
(window 模式、900×700、關硬體加速同本程式),背景圖 = 產生的 3840×2160 JPEG(亮度 60 / 面板 75)。
開設定 = 呼叫假 host 的 `onOpenSettings` 回呼;關設定 = DOM `.click()` ✕。每次開設定量:新的預先處理圖換上的時間、開後 1.5 秒內 longtask、
renderer 行程 CPU(`getAppMetrics` `cumulativeCPUUsage`)、`[bg]` 記錄的各段耗時。情境:
- `cold-*`:啟動後第一次開設定(一般 / 關於分頁);
- `same-size-*`:同大小再開(第 30.6 步的快取換上,不重畫);
- `resized-*`:視窗改大小後再開(= 拖過設定視窗大小 / 換 DPI / 換主題,必須重畫)。

改前 = 本輪 B8 打點後、B9 修正前的建置;改後 = B9 修正後(來源圖保留 + 預覽圖,**不含**最後加的 `redecode()`,見下)。
CPU 含 harness 自己每幀輪詢的底(same-size 那列 ≈ 底 + 掛載設定頁),比較看差值。

### 卡頓根因(哪一段佔多少)
1. **主因:來源圖重新載入 + 解碼,而且與一般分頁的原圖預覽搶同一張圖**。BgLayerImage 卸載時 `dispose()` 釋放原圖,設定視窗大小 / 主題 / dpr 一變
   再開就要整張重抓重解碼:一般分頁上「載入」85–192 ms、「繪製」33–68 ms(drawImage 時再同步解碼 4K 原圖),並產生 25–81 ms 的 longtask;
   同樣的重畫在關於分頁(沒有原圖預覽)載入只要 1 ms、繪製 3–10 ms。renderer CPU 每次開設定多 200–240 ms(dpr 1)。
2. **一般分頁的縮圖 + 兩個位置預覽框**各自用 4K 原圖(縮圖還套 CSS 即時 blur、預覽框各 `new Image().decode()` 一次):本身在快取命中時成本小
   (same-size general vs about 差 5–20 ms CPU),但與第 1 點同時發生時把原圖的解碼拉長,是第 1 點只在一般分頁嚴重的原因。
3. **PNG 編碼 / 解碼**:每次重畫 20–95 ms / 7–24 ms(dpr 1.5 約翻倍),非同步、沒有造成 longtask;本輪不改(不能把 canvas 放進 DOM,見 CLAUDE.md)。
4. **繪製本身(縮放 + 模糊)**:來源圖已解碼時只有 2–10 ms(Skia 的大半徑模糊很快)→ 降解析度模糊沒有收益,評估後不採用(見下)。
5. **設定視窗 v-if 每次重掛**(App.vue,本輪不改):same-size 再開沒有任何背景圖工作時 renderer CPU 仍 70–120 ms(含 harness 輪詢底),
   cold 時另有 55–86 ms 的 longtask 也出現在沒有背景重畫的關於分頁 → 屬於設定頁本身的掛載成本。若要再降,建議評估設定層改 v-show / KeepAlive(需另案,App.vue 由他人負責)。

### 修正
- `bg-bake.ts` `bgSourceCache`:解碼後的來源圖(`<img>`)一次保留一張,BgLayerImage 卸載 / 重畫不再重抓重解碼;換圖 / 背景關閉時 `useBackground` 一起清。
  畫之前 `redecode()`。
- 設定 › 一般:縮圖與兩個位置預覽框共用一張 ≤ 480 px 預覽圖(`useBgPreview` / `bgPreviewCache`,與背景圖層共用解碼後的來源圖);
  縮圖預先畫好亮度 + 模糊(`useBgThumb`),不再對原圖即時套 CSS blur;預覽框不再自己解碼原圖。
- 評估後不採用:
  - **來源圖轉 ImageBitmap**:從 ImageBitmap 縮放的重取樣與 `<img>` 不同,霧面 0 最大差 14/255、dpr 1.5 平均 0.86(超過第 10 步門檻)。
  - **降解析度模糊**(半徑大時先縮小再模糊再放大):霧面 50 / 100 平均差 0.96 / 1.13、最大 14 / 12(超門檻);且繪製本來只有 2–10 ms,
    倍率接近 1 時多出的放大反而更慢(dpr 1.5 霧面 12 繪製 10 → 36 ms)。保留原解析度路徑。
