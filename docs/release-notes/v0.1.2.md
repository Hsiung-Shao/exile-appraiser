## 新增

・**英文遊戲客戶端辨識**：PoE2 褻瀆揭露面板與符文塑形支援英文遊戲畫面。（需 Windows 英文 OCR 語言包）
・**辨識語言設定**：OCR 辨識語言可獨立選擇，介面繁中也能辨識英文遊戲。（設定 › 熱鍵與視窗）
・**查價自動判斷語言**：國際服依複製的物品文字自動用中文或英文解析，不必切換客戶端語言。
・**通貨價格區**：PoE1 / PoE2 查通貨時顯示兌換比、7 天走勢、每小時成交量與堆疊總值。
・**滑鼠懸停顯示物品**：PoE2 查價結果移到掛單上可看到完整物品，詞綴顯示繁中。（設定 › 查價可選關閉 / SHIFT / 始終）
・**未鑑定傳奇**：PoE2 查未鑑定傳奇時先列出可能的傳奇讓你選擇再查價。
・**倉庫頁籤捲動**：遊戲中按住 Ctrl 滾動滑鼠滾輪切換倉庫頁籤。（移植自 Awakened PoE Trade，可在熱鍵分頁關閉）
・**徽章外觀**：褻瀆與符文徽章可調整字體、大小、粗體、外框與三段價格顏色。
・**市集徽章分色**：符文塑形的市價徽章依崇高石等值套用三段價格顏色。
・**辨識開關提示**：按褻瀆 / 符文暫停熱鍵時顯示「已啟動 / 已暫停」；兩鍵相同時一次切換兩者。
・**遊戲啟動提示**：程式已在背景時開啟遊戲，也會再顯示一次「已在背景執行」。
・**設定視窗大小與字級**：設定視窗可拖曳調整大小與位置並記住，字級可獨立設定。
・**背景圖位置**：可在預覽圖上拖曳選擇顯示位置，並選填滿 / 完整顯示 / 縮放。（查價面板與設定視窗各一組）
・**記錄分頁**：設定 › 記錄可直接看程式記錄、篩選錯誤並一鍵複製，方便回報問題。

## 修正

・**褻瀆徽章**：徽章顯示後會少一枚、接著整組消失，約每 3 秒重複一次。
・**褻瀆誤判**：框了辨識區域時，游標指著背包物品會在物品浮窗旁畫出錯誤徽章。
・**褻瀆徽章重疊**：同一面板的徽章互相重疊、左右錯開。
・**褻瀆底材推算**：剛查過另一件物品的價，開井時部分詞綴顯示「此底材擲不出」。
・**未鑑定傳奇珠寶**：查價面板一片空白。
・**查價面板**：在部分安裝路徑下，游標移開不會自動關閉面板。
・**設定頁 Regex 對話框**：設定視窗字級調大時按鈕文字被切掉。

## 調整

・**效能**：降低遊戲中的背景 CPU 用量，OCR 擷取與辨識明顯變快。（褻瀆 / 符文持續辨識、熱鍵掛鉤、Regex 寶石頁記憶體）
・**熱鍵名稱**：「切換 overlay 焦點」→「設定選單」。
・**提示位置**：啟動提示與辨識開關提示改顯示在遊戲所在的螢幕。
・**褻瀆辨識區域**：框了區域後只看區域，區域內沒找到面板時不再改找整個畫面。
