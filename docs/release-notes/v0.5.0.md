## 新增

・**計時器三種模式**:speedrun(分段、個人最佳、讀遊戲記錄自動分段)、一般計時器、倒數計時,在設定 › 計時器切換。一般計時器與倒數計時可設定提醒音效,也能匯入自己的音檔。
・**speedrun 每次嘗試都會存一筆紀錄**:設定 › 計時器 › 紀錄可以改名、展開看各段時間、刪除,也能選一筆當比較對象(計時器差值跟它比),或設為個人最佳。
・**PoE1 地圖詞綴檢查**:對單張地圖按熱鍵,依正則書籤標出要排除或要求的詞綴。
・**PoE1 查價結果懸停浮窗**:查價結果上可以看到物品浮窗,詞綴與類別盡量翻成繁中。

## 修正

・**PoE2「相當不幸」類詞綴顯示成「相當幸運」**:沒有數字的反向詞綴(例如敵人擊中你的閃電傷害相當不幸、帶來厄運)現在照原句顯示,查詢只查不幸的。
・**PoE1 / PoE2 汙染篩選照按鈕送出**:選「已汙染」送已汙染、選「未汙染」送未汙染(以前「已汙染」等於不限)。
・**PoE1 / PoE2 破裂詞綴可以切換**:破裂詞綴那一列不用開「機制」開關也看得到「破裂」切換。
・**個別詞綴修正**:永恆珠寶的征服者名、瑪茲科特爾的虛榮、召喚物與傭兵相關詞綴等,依 3.30 資料與回報補上正確寫法。

## 調整

・**speedrun 中途開始**:從章節中途開始也會自動分段,該次不寫入個人最佳。
・**PoE2 計時器預設分段**:依遊戲章節名稱推定,尚未實機確認。
