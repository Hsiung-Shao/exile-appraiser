## 修正

・**PoE1 腐敗之種的天賦顯示為未解析**：洗出的天賦若是 3.30 改過名的，現在可以查價了。（例如破壘者）
・**PoE1 黑暗君主「異蛛復甦的最大數量加倍」顯示為未解析**：繁中客戶端帶入的是技能名。
・**PoE1「命運」物品與「未鑑定（階級 N）」無法查價**：可以解析，查詢會帶未鑑定、階級與命運條件。
・**PoE1 臟器的固定詞綴顯示為未解析**：例如巫會之后冠的「更多最大物理攻擊傷害」。
・**PoE1 英文地圖的壁壘固定詞綴認不出**：「Map contains X's Citadel」可以解析了。
・**PoE1 進階複製的「(...)」標記造成未解析**：標記出現在哪個位置都能解析。
・**PoE1 地圖物品上的詞綴另一種寫法認不出**：同一條詞綴在地圖物品與輿圖天賦上的兩種句子都能解析。
・**PoE1 穢生物品篩選查不到**：改用交易站現行的欄位。
