## 修正

・**破裂詞綴搜不到**：正則「物品詞綴數值」勾的詞綴是破裂詞綴時，倉庫與商店搜尋不會亮。
・**碑牌詞綴缺條目**：碑牌詞綴頁少了「探險炸藥範圍」「瓦爾遺物」等詞綴。（PoE2）
・**碑牌詞綴的另一種寫法搜不到**：同一條碑牌詞綴在遊戲裡有兩種寫法時，只認得其中一種。（PoE2）

## 新增

・**更多可篩數值的詞綴**：物品詞綴數值頁多了施法速度、格擋機率等原本無法選的詞綴。（PoE2 新增 96 條、PoE1 新增 69 條）
・**碑牌正則只亮碑牌**：只勾碑牌詞綴時，產生的字串會限定碑牌，不再亮到其他物品。（PoE2）

## 調整

・**合併正則只合同類物品**：不同類物品的頁（例如碑牌與換界石）不再合成同一條，稀有度與汙染條件寫得更短。
・**寶石名稱可與寶石等級、品質合併**：選寶石名稱時，可再加上寶石等級或品質條件。

說明：物品詞綴數值頁產生的字串會稍微變長。舊的正則書籤與分享碼照常可用。
