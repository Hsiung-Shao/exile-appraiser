## 修正

・**PoE1 倉庫價格**：超寬螢幕（遊戲左右有黑邊）時，價格疊層不出現。（32:9 等比例）
・**PoE1 倉庫價格**：倉庫頁籤或資料夾頁籤剛好叫「一般」時，價格疊層可能一直不出現。
・**查價面板聯盟**：標題列與掛單選單的聯盟不同步。（改任一邊，另一邊跟著變）
・**正則排除條件**：片段開頭是空白時，會多排除不相干的地圖。（例：Courthouse、Lighthouse）
・**正則商店頁**：連結數條件會誤中「物理傷害: 10-20」這類數字行。
・**正則誤中**：搜尋字串會誤中其他物品的風味文字與用途說明。
・**正則分享碼**：英文同名的詞綴會還原到錯的那一列。

## 新增

・**正則自訂書籤**：自己寫的搜尋字串可以存成書籤。（資料夾、熱鍵、書籤列、快速面板照用）
・**正則輸出框**：可以直接修改或輸入自己的字串，再按「存成自訂書籤」。
  ⚠ 手動輸入的字串會原樣貼進遊戲，不經驗證。
・**計時器**：仿 speedrun 的章節計時，有分段、總時間與個人最佳比較。（設定 › 一般；熱鍵預設未設定）
  ⚠ 自動開始與自動分段預設關閉；PoE2 間章的順序尚未實機確認，可在設定頁調整。
・**在 poedb 開啟物品**：滑鼠指著物品按熱鍵，用瀏覽器開啟 poedb / poe2db 的物品頁。（熱鍵預設未設定）
・**PoE1 正則新頁面**：野獸、魔法物品詞綴名。
・**查價面板**：詞綴收合後多一顆「展開詞綴」按鈕。

## 調整

・**移除聖甲蟲功能**：倉庫價格的聖甲蟲頁、正則與地圖查價的「更多聖甲蟲」條件。（3.30 已移除聖甲蟲）
・**PoE1 倉庫價格**：碎片頁的辨識放寬，配合少一顆按鈕的版面。
  ⚠ 尚未在 3.30 實機確認。
・**正則商店頁**：連結與顏色條件改為任一成立，3 連以上的字串變短。
・**支援遊戲版本**：關於頁的 PoE1 版本 3.29.3 → 3.30.0。

說明：設定檔、正則書籤與分享碼沿用舊格式；舊書籤裡的「更多聖甲蟲」條件會被略過。
