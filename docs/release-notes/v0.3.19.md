## 修正

・**PoE1 二次汙染的物品查價**：查詢會帶上「二次汙染」條件，不再混進一般汙染的物品。
・**PoE1 不可能的逃脫查不到**：3.30 改名的基石（精準技巧、邪惡結界）可以解析與查價了。
・**PoE1 奇塔弗之渴望查到 0 筆**：改為只送交易站有索引的機率數值。
・**PoE1 輿圖聖物部分詞綴顯示為未解析**：區域內的寫法（保險箱、儀式重擲、軍團中士等）可以解析了。
・**PoE1 英文客戶端部分傳奇多行詞綴被拆開**：「視為有最大數量的耐力 / 狂怒 / 暴擊球」與德瑞肖像會解析成一條。
・**PoE1 交易站新上架的詞綴查不到**：殲滅輔助、破裂的前綴不能被更改可以查價了。

## 新增

・**速查表可存多張**：匯入時可一次選多張圖，用上方按鈕切換。
・**速查表再放大**：釘住後可用滾輪放大、拖曳移動，標題列也有放大 / 縮小 / 整張顯示。（雙擊切換 100% 與 200%）
・**PoE1 海圖詞綴可勾選**：固定與隨機詞綴收在「已隱藏」，預設不勾。
