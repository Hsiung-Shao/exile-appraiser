## 新增

・**物品詞綴數值正則**：正則新增「物品詞綴數值」頁，可搜尋詞綴並設定數值，例如最大生命 ≥ 80。（PoE1 / PoE2 皆有）
  ⚠ 只支援單一數值的詞綴，「附加 # 至 # 傷害」這類暫不提供。
・**正則書籤資料夾**：書籤可分資料夾，書籤列與快速面板依資料夾分組、可收合。（可拖曳排序）
・**正則書籤分頁**：書籤管理分成 PoE1 / PoE2 兩頁，不切遊戲也能編輯另一代的書籤。
・**熱鍵總表**：所有熱鍵集中在設定的「熱鍵」頁設定，重複時即時標示。（聊天指令也能直接在這裡設）
・**回到熱鍵**：從熱鍵總表跳到其他頁時，頂端可一鍵回到熱鍵。

## 修正

・**在瀏覽器開啟設定**：切換分頁後按瀏覽器上一頁，會整個離開設定頁且回不去。

## 調整

・**設定頁重新整理**：選單分成「設定」與「工具」兩組，新增「遊戲」「倉庫與聊天」「自動辨識」頁。
・**設定說明精簡**：說明縮成一句，詳細內容收進「?」；不適用目前遊戲或伺服器的選項不再顯示。
・**系統匣選單**：右鍵只留在瀏覽器開啟設定、版本、檢查更新、結束。（雙擊圖示開設定）
・**開啟設定資料夾**：從系統匣移到設定 › 更新與關於。
・**未設定的熱鍵**：選填熱鍵沒設時改為灰字，紅字只表示衝突或無法註冊。

說明：既有的正則書籤升級後全部放在「未分類」，內容與熱鍵不變。
