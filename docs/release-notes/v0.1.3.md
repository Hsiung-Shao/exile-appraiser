## 新增

・**正則書籤快捷列**：開設定選單時旁邊列出正則書籤，點一下就貼進遊戲搜尋列。（需先開著倉庫或商店）
・**正則快速面板**：設定熱鍵叫出書籤清單，用方向鍵或數字鍵選了就貼。（設定 › 熱鍵，預設不綁）
・**正則書籤熱鍵**：每個書籤可設自己的熱鍵，按下直接貼進遊戲搜尋列。
・**正則稀有度條件**：地圖與換界石數值條件可篩選普通 / 魔法 / 稀有 / 傳奇。
・**新版本提醒**：有新版本時每 10 分鐘提醒一次，可立即更新、稍後或略過此版本。（設定 › 關於可關閉）
・**硬體加速選項**：可自行開啟硬體加速，重新啟動後生效。（設定 › 一般，預設關閉）
・**效能診斷**：可記錄程式的 CPU 與記憶體用量，方便回報效能問題。（設定 › 記錄）

## 修正

・**正則數值條件**：會誤中不是地圖屬性的詞綴說明文字。（例如凋落保險箱的物品數量說明）
・**程式開著不關**：長時間執行時收不到新版本。

## 調整

・**正則數值條件位置**：移到地圖詞綴 / 換界石詞綴頁頂端，和詞綴合成同一條正則。（不再是獨立頁面）
・**正則數值寫法**：改用遊戲常見的「標籤: +數值%」寫法與 [0-9]，較好閱讀。（字數比以前多；階級改比對物品名稱）
・**效能**：遊戲中閒置時隱藏覆蓋視窗、減少背景檢查，降低對遊戲的影響。
・**倉庫頁籤捲動**：只在按住 Ctrl 時才監聽滑鼠滾輪。
・**更新檢查**：每 16 小時 → 每 2 小時。
・**遊戲偵測**：遊戲沒開時放慢檢查頻率。
  ⚠ 開啟遊戲後最慢約 12 秒才會被偵測到。

說明：舊的正則書籤與分享碼照常可用；新版產生的分享碼無法匯入舊版。
