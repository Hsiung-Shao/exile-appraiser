## 修正

・**未鑑定傳奇查價空白**：PoE1 查未鑑定的傳奇裝備時，查價區什麼都不顯示。現在會先問是哪一件傳奇（只有一件時自動選定）再查價。
・**假掰（The Adorned）詞綴無法辨識**：遊戲內複製的「增加 #% 天賦樹插槽內的已汙染魔法珠寶效果」現在認得，會列入查價。
・**語言不符的提示**：PoE2 物品文字語言與客戶端語言設定不同時，提示改成看得懂的句子。
・**啟動時的錯誤視窗**：程式剛啟動時再開一次，會跳出 JavaScript 錯誤視窗。

## 新增

・**懸浮選單**：在遊戲裡按 Shift + Space（沒有查價面板時）叫出選單，有「設定」「正則書籤」「速查表」三個按鈕；選單可以拖曳，位置會記住。
・**選單內的正則書籤**：可切換 PoE1 / PoE2，每個書籤下方直接顯示正則內容；目前遊戲的書籤點一下就貼進遊戲，另一款遊戲的只複製。
・**密教速查表**：內建 3.29 版密教速查表，滑鼠移上去放大、點一下釘住；釘住後可移動、調整大小。也可以匯入自己的圖片，或還原成內建。
・**回報按鈕放在問題旁邊**：無法辨識的詞綴旁有「回報這條」，詞綴清單上方會提示有幾條無法辨識；查價失敗、物品無法辨識時也直接有回報按鈕。
・**正則稀有度 / 汙染條件**：物品基底、商店、物品詞綴數值、碑牌詞綴頁也能篩稀有度與是否汙染。（碑牌詞綴只在 PoE2）
・**未汙染篩選**：可以只找沒汙染過的地圖、換界石與物品。
・**從 PobTools 送正則**：PobTools 可一鍵把選好的正則書籤或目前的勾選送進來，確認後才加入。（需要 PobTools 對應版本）
・**支援遊戲版本**：設定 › 更新與關於顯示目前支援的 PoE1 / PoE2 版本。

## 調整

・**Shift + Space 改開懸浮選單**：以前會直接打開設定，現在先出選單，點「設定」才開設定視窗。系統匣與其他入口仍直接開設定。
・**地圖 / 換界石稀有度**：可同時選多種稀有度，並和汙染條件放在同一列。
・**背景圖模式的版面**：查價區各區塊左右留白，勾選框、數值框、「交易」不再貼邊。
