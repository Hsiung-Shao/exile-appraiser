## 新增

・**首個公開版本**：ExileAppraiser（流亡鑑價），PoE1 與 PoE2 共用一支的查價工具。（僅支援 Windows）
・**PoE1 / PoE2 自動切換**：依前景的遊戲視窗自動換成對應的遊戲，不必手動改設定。
・**國際服 / 台服查價**：兩區交易站都能查，繁體中文與英文客戶端的物品都能解析。
・**遊戲內 overlay**：滑鼠移到物品按熱鍵，查價結果直接在游標旁彈出。（也可改用獨立視窗）
・**介面語言與主題**：介面可切中文 / English，另有四種主題、強調色與字級。
・**Poe Regex 搜尋字串產生器**：PoE1 10 頁、PoE2 7 頁詞綴清單，勾選後產生遊戲搜尋列字串。（另有地圖數值與商店條件頁）
・**Regex 合併、分享碼與範本**：多頁勾選合成一串、整組分享給別人，並內建常用範本。
・**拆粉**：查價面板顯示傳奇能拆出的粉塵與每 chaos 效率。（價格來自 poe.ninja，僅國際服）
・**拆粉排行**：設定視窗內列出所有傳奇的拆粉效率，一鍵開交易站。
・**瀏覽器預覽**：在一般瀏覽器看、改設定，改動即時同步回 overlay。（只開在本機）
・**PoE2 褻瀆詞綴 Tier**：進階複製直接顯示 Tier，一般複製依詞綴資料推定並標示「推定」。
・**PoE2 靈魂之井三選一辨識**：在揭露面板按熱鍵，每個選項旁顯示褻瀆詞綴的 Tier 與數值範圍。
  ⚠ 需要 Windows 繁中 OCR 語言包；全螢幕獨占模式可能擷取不到畫面，請用無邊框視窗。
・**辨識區域框選**：可在遊戲畫面上框出揭露面板或符文塑形面板的位置，辨識更快更準。
・**PoE2 符文塑形自動查價**：開著符文塑形面板時，每一列旁顯示參考價。（僅國際服，預設關閉）
・**一鍵回報**：查價出錯時整理成回報草稿，由你確認後自己送出。（不含帳號名）
・**自動更新**：安裝版在背景下載新版，正常結束程式時自動套用。（可在設定 › 關於關閉）
・**更新只下載差異**：之後的新版只下載有變動的部分，更新更快。（下載不到差異時改下載完整安裝檔）
・**啟動提示**：啟動後右下角短暫顯示「已在背景執行」與查價熱鍵，更新後會顯示新版號。（可在設定 › 一般關閉）

說明：辨識一律在本機以 Windows 內建 OCR 執行，截圖不存檔、不上傳，也不會對遊戲送出任何按鍵。
