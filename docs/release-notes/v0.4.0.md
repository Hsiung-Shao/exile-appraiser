## 修正

・**PoE1 倉庫價格在部分螢幕比例、UI 縮放或資料夾內位置跑掉**：改用畫面上的格子位置對齊，不再依螢幕高度推算座標，也不讀子頁按鈕文字。
・**PoE1 倉庫價格在說明框蓋住按鈕、或英文介面時不出現**：同上，判斷子頁與位置都看格子本身。
・**PoE1 純才顯示為未解析**：3.30 每個職業各一條的寫法可以解析了，也不會再被當成一般詞綴送錯條件。
・**PoE1 寶石匠的稜鏡查到經驗不夠的**：查詢會帶上「已儲存經驗」，以物品上的數值當最低值。
・**PoE1 阿茲瓦特史記、探險日誌地區等級被往下截**：84 等的史記不再用 80 查，日誌照原本的地區等級查。
・**PoE1 地圖多送了「更多聖甲蟲」條件**：3.30 已移除聖甲蟲，地圖查詢不再帶這個偽屬性。
・**PoE1 正則地圖數值區**：改用 3.30 的「輿圖掉落物」；偽屬性不再顯示「來自 0 條詞綴」。

## 新增

・**設定 › 記錄「匯出記錄檔」**：一鍵存成檔案（含版本、系統與設定摘要，不含帳號），回報問題時附上即可。
・**查價與倉庫價格的診斷記錄**：記錄裡看得到查價有沒有觸發、讀到什麼、交易站回應，以及倉庫價格沒出現的原因。

## 調整

・**PoE1 倉庫價格「OCR 區域」改名為「搜尋區域」**：只要框住倉庫格子的大概範圍；舊版框的按鈕列區域會自動改用預設範圍。
・**PoE1 倉庫價格切換子頁**：會先收起再出現，約 3 秒。
