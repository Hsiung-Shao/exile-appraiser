## 新增

・**符文塑形自動查市集**：poe.ninja 沒有價格的列會自動查交易站，徽章直接顯示市價。（查價面板開著時暫停，不拖慢一般查價）
・**市價徽章顯示篩選**：技能寶石帶等級、未汙染、無品質篩選，徽章標出「L20」「等級不限」。（掛單少於 3 筆標示「少」）
・**PoE2 褻瀆詞綴自動辨識**：揭露面板開著就持續辨識，不必每次按熱鍵。（預設開啟，原熱鍵改為暫停 / 繼續）
・**聊天指令熱鍵**：按熱鍵在遊戲聊天框輸入指令，例如回藏身處、回覆最後私訊的人。（移植自 Awakened PoE Trade，僅 overlay 模式）
  ⚠ 預設 F5 送出 /hideout、F9 送出 /exit；不需要請到設定 › 聊天指令刪除或清空熱鍵。
・**倉庫搜尋熱鍵**：按熱鍵在倉庫搜尋框填入自訂字串並套用。（Poe Regex 頁可一鍵「加到倉庫搜尋」）
・**自訂背景圖**：查價面板與設定視窗可放背景圖，並調整亮度、面板不透明度與霧面。（支援 png / jpg / webp）
・**背景上的文字對比**：面板調成透明時自動加強文字對比，字不會淹沒在圖裡。
・**符文塑形框選熱鍵**：符文塑形面板也能用熱鍵框選辨識區域。（預設未設定）
・**使用說明**：README 改為中英雙語，加入下載說明、各功能教學與贊助連結。

## 修正

・**熱鍵設定**：以 Alt 起手的組合（如 Ctrl+Alt+D）錄不進去，先放開 Alt 還會少錄一鍵。

## 調整

・**按住 Alt 隱藏 overlay**：移除此行為，按 Alt 不再讓查價面板與徽章消失。
・**褻瀆與符文塑形設定**：兩者改用同一套設定項目，暫停 / 框選熱鍵移入各自區塊。
・**掃描間隔下限**：500 ms → 100 ms。（低於 500 ms 會提示 CPU 用量）
・**褻瀆辨識區域**：移除「手動輸入比例」，改用框選設定。（已設定的區域照舊沿用）
・**符文塑形「未發現」列**：尚未解鎖的配方列不再比對、不畫徽章。
