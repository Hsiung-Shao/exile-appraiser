## 新增

・**PoE1 倉庫價格**：打開碎片頁的「一般」「聖甲蟲」子頁時，每一格直接標上 poe.ninja 價格（C / D）；滑鼠停在某一格只放大那一格。只支援國際服。
・**倉庫價值**：讀出每格的堆疊數量，徽章改顯示小計，倉庫面板底部顯示「本頁價值」。讀不到數量或沒有價格的格子會標「?」或「無價」，不計入總價。數量是畫面辨識，可能讀錯，請以遊戲內為準。
・**倉庫價格顯示方式**：可選「自動偵測」（打開倉庫自動出現）或「按熱鍵顯示」（平常完全不截圖，按熱鍵才辨識，關倉庫自動收起）。設定 › 自動辨識 › 倉庫價格。
・**價值卡可拖曳**：叫出懸浮選單時，本頁價值卡可以拖到想要的位置，會記住；選單裡可還原位置。
・**PoE1 自動辨識熱鍵**：倉庫價格的暫停 / 繼續與框選辨識區域熱鍵，在設定 › 熱鍵設定。
・**查價結果滑鼠懸停物品**：PoE1 也能把滑鼠移到掛單上看物品詳細，詞綴、類別、需求顯示繁中（國際服、介面繁中時）。
・**懸浮選單改版**：搜尋框 + 分類（全部 / 書籤 / 辨識 / 工具）、鍵盤上下選擇；標題列切換聯盟、顯示查詢限流狀態；新增匯率列（1 神聖石 = 多少混沌石 / 崇高石與 7 天走勢）、倉庫本頁價值、各自動辨識開關。
・**記錄頁除錯工具**：「存下倉庫擷取畫面」可把程式實際看到的倉庫畫面存下來，回報倉庫辨識問題時使用。

## 調整

・**查價面板改版**：詞綴與偽屬性分成兩張卡片，用開關與範圍膠囊調整；掛單可切換方塊 / 長條兩種顯示，物品與通貨各自記住。
・**通貨價格區**：通貨查價頂端顯示 poe.ninja 兌換價、7 天走勢與成交量；有價值的底材會標「底材」。
・**PoE2 通貨圖示**：改用 PoE2 自己的圖示（原本與 PoE1 共用）。
・**魔法 / 稀有底材預設查同一底材**：查魔法 / 稀有的武器、防具、飾品、箭袋時，預設只找同一個底材，不會混進其他底材（可在名稱處切回類別）。
・**破裂詞綴**：破裂詞綴預設顯示在詞綴清單裡，數值照一般詞綴呈現，按下「破裂」才改查破裂。
・**PoE2 物品浮窗**：啟動後先在背景載入翻譯，第一次查價就是中文；物品類別改用遊戲內的繁中名稱。
・**設定頁整理**：自動辨識移到工具組第一個、三張辨識卡片統一樣式；關於頁的資料來源只留 poe.ninja，支援遊戲版本改成更醒目的顯示；熱鍵總表不再重複列出聊天指令。
・**大螢幕字級**：字級上限放寬到約 3 倍，4K 螢幕也能放大。

## 效能

・**倉庫掃描省電**：沒打開倉庫時每 3 秒才檢查一次；遊戲用「獨占全螢幕」時（overlay 本來就畫不出來）不再嘗試擷取。
・**開設定卡頓**：使用背景圖時打開設定不再卡一下（背景圖改成預先處理並快取）。
・**懸浮選單**：書籤預覽改為快取、分批計算，叫出選單不再卡頓。
・**效能記錄**：設定 › 記錄 › 效能可記錄整個程式（含畫面、查價延遲、背景圖）的效能資料，方便回報問題。

說明：倉庫價格與倉庫價值只支援國際服。倉庫格子位置依固定版面，非 16:9 或特殊解析度若對不準，可在設定裡框選辨識區域校正。
