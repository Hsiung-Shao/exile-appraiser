# Regex 物品詞綴數值頁:因多種寫法而未收錄的詞綴(出現位置查詢表)

> **用途**:使用者回報「物品詞綴數值頁找不到某條詞綴 / 勾了搜不到」時,先在這裡搜英文 ref 或繁中寫法,確認是不是已知的排除項、出在哪種物品、原因為何。
> **快照日期**:2026-10-10(v0.2.3;資料集 ee2-patched fc7de73 / apt-patched 384d1c5;仲裁檔 `data/regex/item-mod-forms.json`)。
> 資料同步或仲裁檔重產後清單會變:以 `regex/test/item-mod-forms.test.ts` T9 與 `item-mods.test.ts` 排除統計的數字為準,差很多時重做本表。
> **重產方式**:列出「多種寫法且未收錄」的 stat(`buildItemModData` 帶 / 不帶仲裁比對)→ 以 GGPK stat id(PoE1 用交易站 stat id 對 PoB `Mod*.lua` 的 `tradeHashes`)在 PobTools 本機 GGPK 快取的 `mods.datc64` 找 Domain / GenerationType / 生成權重標籤(PoE2 mods 表列寬 693、標籤位移 158、權重位移 677,見 Obsidian〈PoE2 GGPK 佈局與 bundle 定址〉)。當時的解碼腳本為一次性工具,未收進 repo。
> 相關:`docs/regex-port.md` 第 37 步「多種寫法仲裁」;排除總數另見該節。

## 資料來源

- 排除清單:當時匯出的排除清單(60 條:PoE1 19、PoE2 41)。
- 詞綴模板資料集:`data/poe2/{cmn-Hant,en}/stats.ndjson`(ee2-patched fc7de73)、`data/poe1/...`(apt-patched 384d1c5)。
- PoE2 GGPK:`Pob2/pob-zh-engine/tools/ggpk2_zh/cache/data/balance/{mods,stats,tags}.datc64`(game_version 0.5.5.4.2,2026-10-08 抽)。抽取的 `out/poe2/tables/mods.json` 只有本地化字串、沒有 stat/Domain 欄,故改自行解碼原始 datc64。mods 表實際列寬 693 bytes、偏離 dat-schema(653),依 Obsidian〈PoE2 GGPK 佈局與 bundle 定址〉的反推法:Domain/GenerationType/Stat 取 schema 位置,SpawnWeight_Tags 取位移 158、權重取位移 677(16,784 列「標籤數 = 權重數」全數一致,0 筆不符)。
- PoE1 GGPK:`tools/ggpk_zh/cache/data_all/data/{mods,stats,tags}.datc64`(3.29.0.1,schema 吻合 654 bytes)。
- PoB 資料:`Pob2/pob-zh-engine/dist/PathOfBuildingCommunity{,-PoE2-Portable}/Data/Mod*.lua`(以 tradeHashes 的交易站 stat id 對應 mod id 與權重標籤)。
- 名稱對照:Domain / GenerationType 取 dat-schema 列舉;PoE2 常用值(1 裝備、6 地圖/換界石、28 UNVEILED=褻瀆、29 探險遺物、34 碑牌)依 Obsidian 筆記;碑牌種類由 `tower_augment_*` 標籤對照 baseitemtypes(探險 / 譫妄 / 祭祀 / 深淵 / 總督 / 裂痕 / 神廟 / 輻照)。

## 判定方法

1. PoE2:用 `ggpkId` 在 mods 表找出所有含此 stat 的列;彙整 Domain、GenerationType(1 前綴 / 2 後綴 / 3 傳奇固有)、正權重標籤。標籤只有 `default` 權重 1 = 該 Domain 任何物品皆可出;`default` 權重 0 的列視為 PoE1 遺留 / 現行不可生成(PoE2 mods 表混有大量 PoE1 遺留列)。
2. PoE1:`ggpkId` 皆為 null,改用交易站 stat id 對 PoB `tradeHashes` 找出 mod id,再回 GGPK mods 表取 Domain / GenerationType;兩邊都找不到者,依交易站分類與英文文字「推斷」。
3. 排除原因:no_arb = poe2db / poedb 皆查無;arb 僅 1 種 = 仲裁單一但太長或多行;arb ≥ 2 種 = 算共同前 / 後綴,差異段含 `#` → `#` 位置不同,否則太長 / 其他。
